# ✈️ Huokaing Thara Air Travel & Tour — Web Engine

A modular, lightweight front-end web architecture for **Huokaing Thara Air Travel & Tour**. This repository contains the interactive components, dynamic flight booking tools, multilingual engines, and structural layouts powering regional aviation ticketing and heritage expedition portals across Southeast Asia.

## 🌟 Key Features

* **Multi-Module JavaScript Architecture (`script1.js` – `script11.js`)**: Isolated functional scripts handling specific tasks such as flight search UI, interactive activity filters, and cultural guides.
* **Google Translate Engine (10 Languages)**: Native multi-language switching initialized for Khmer (`km`), English (`en`), French (`fr`), Chinese (`zh-CN`), Thai (`th`), Lao (`lo`), Japanese (`ja`), Korean (`ko`), Vietnamese (`vi`), and German (`de`).
* **Interactive Activity Filter**: Dynamic client-side filtering for tour categories (Cultural, Water, Trekking) and effort difficulty levels.
* **Responsive & Accessible Design**: Zero-dependency CSS Grid and Flexbox system supporting desktop and mobile viewports.
* **No External Framework Overhead**: Pure Vanilla JS, HTML5, and CSS3 for high performance and minimal resource usage.

## 📂 Repository Structure
